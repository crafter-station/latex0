# Web fonts for the exact page view

Generated by `packages/engine/tools/webfonts/build.py` from the Type 1 fonts pdfTeX embeds (TeX Live 2025,
`pdftex.map`): outlines only, converted to WOFF2, one file per Type 1 file.

- `cm*`, `ms*`, `eufm*`, `lasy*`, `line*`, `lcircle*`: the AMS Type 1 versions of Computer Modern and the
  AMS/LaTeX fonts (`fonts/type1/public/amsfonts`), SIL Open Font License 1.1.
- `sf*`: CM-Super (`fonts/type1/public/cm-super`), the T1 and TS1 encoded Computer Modern, GNU GPL; the
  sources are on CTAN (https://ctan.org/pkg/cm-super).
